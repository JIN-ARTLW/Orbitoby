# Contributing to Orbitoby / 기여 안내

Orbitoby is a public research software project.

## Development principles / 개발 원칙

- Core architecture and scientific decisions require human approval.
- AI-assisted contributions must be reviewed and validated.
- Preserve backward compatibility and existing research data.
- Record major architecture decisions in ADR documents.
- New data sources require documented provenance, licensing,
  authentication requirements, and validation tests.
- Never commit credentials, local archives, or personal datasets.
- Use conventional commits: feat, fix, test, docs, refactor, chore.

## Current status / 현재 상태

Orbitoby is actively developing toward v0.1.0.
The public API and storage formats are not yet stable.

한국어: 핵심 설계와 연구적 판단은 프로젝트 관리자가 승인하며,
AI는 구현 보조 및 반복 작업에 활용합니다. 모든 변경은 실제 테스트로
검증하고, 중요 결정은 기록합니다.
