# 라이선스와 인용 / Licensing and citation

Orbitoby 코드의 공식 라이선스는 저장소 [LICENSE](../../LICENSE)의 Apache License 2.0 원문입니다. 법적 원문은 수정·대체하지 않았으며 이 안내는 요약입니다. [NOTICE](../../NOTICE)에는 저작권과 자산 구분이 있습니다.

The authoritative code license is the original Apache License 2.0 text in [LICENSE](../../LICENSE). It has not been modified or replaced; this guide is a summary. [NOTICE](../../NOTICE) identifies copyright and asset boundaries.

Toby 마스코트·사진·브랜드 원본은 별도 허락이 없는 한 Apache-2.0에 포함되지 않습니다. 외부 dataset·model·backend는 각자의 라이선스·인용·재배포 조건을 따릅니다.

Toby mascot, photographs, and original brand artwork are excluded from Apache-2.0 unless separately permitted. External datasets, models, and backends retain their own licensing, citation, and redistribution terms.

정식 인용 metadata가 없을 때는 Jin Yeseo, Orbitoby, 사용 버전과 저장소를 인용하고 원 데이터·모델도 별도 인용합니다. 향후 CITATION.cff와 DOI는 확인된 저자·버전·공개 기록으로만 채웁니다.

Until formal citation metadata exists, cite Jin Yeseo, Orbitoby, the version used, and the repository, and cite original data/models separately. Future CITATION.cff and DOI metadata must use verified authorship, version, and public records.

version DOI와 concept DOI를 구별하고, 예약 DOI·비공개 draft를 공개 보존 완료로 표시하지 않습니다. DOI는 최신 릴리스 준비 합의상 PyPI 패키지 검사 blocker가 아니지만 장기 학술·재현성 목표에는 남습니다.

Distinguish version and concept DOIs; a reservation or private draft is not completed public preservation. Under the latest release-preparation agreement, a DOI is not a PyPI package-check blocker, but it remains a scholarly and reproducibility objective.
