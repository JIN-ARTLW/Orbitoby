# Security Policy / 보안 정책

Orbitoby is currently in pre-release development.

## Credentials

Users must supply their own provider credentials.
Never publish .env files, API keys, passwords, tokens,
or private research archives.

## Reporting vulnerabilities

Please report suspected security vulnerabilities privately
to the repository maintainer rather than opening a public
issue containing exploit details or sensitive information.

GitHub: https://github.com/JIN-ARTLW/Orbitoby

한국어: 인증정보와 비공개 데이터는 GitHub에 업로드하지 마세요.
보안 취약점은 민감한 내용을 공개 Issue에 작성하지 말고
관리자에게 비공개로 전달해 주세요.
